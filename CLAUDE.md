# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Environment

- Python 3.12, managed via `uv` with a `.venv` virtualenv
- Install dependencies: `uv sync`
- Run scripts from the repo root so relative paths to `data/` resolve correctly

## Commands

**Lint:**
```bash
uv run ruff check src/
uv run ruff format src/
```

**Run a model** (must be run from repo root; scripts use relative `data/` paths):
```bash
uv run python src/logres.py
uv run python src/xgb.py
uv run python src/mlp.py --epochs 1000 --patience 50
```

All scripts accept `--matrix` and `--adjlist` to override default data paths.

## Architecture

This is an MLflow-based ML experimentation repo for fraud detection on the **YelpChi** dataset (graph-structured, ~45k nodes with 32 features each, binary labels).

### Data pipeline (`src/dataset.py`)
- `load_dataset(matrix, adjlist)` — loads the `.mat` file, extracts labels/features, builds a homogeneous adjacency list from the sparse `homo` relation, saves it as a pickle, then returns `(labels, features, homogenous)`.
- `split_dataset(features, labels)` — stratified 80/20 train/test split.

### Models (each is a standalone script)
| File | Model | Framework |
|------|-------|-----------|
| `src/logres.py` | Logistic Regression | scikit-learn |
| `src/xgb.py` | XGBoost | xgboost |
| `src/mlp.py` | MLP (32→64→1) with early stopping | PyTorch |
| `src/gcn.py` | Graph Convolutional Network (in progress) | PyTorch Geometric |

Each script imports from `dataset.py` using a bare `from dataset import ...`, so they must be run with the `src/` directory on the Python path (achieved by running via `uv run python src/<script>.py` from repo root).

### Metrics reported
ROC AUC, F1-score, Precision, Recall — all models use threshold 0.5 for binary predictions.

### Data files (gitignored)
- `data/YelpChi.mat` — main dataset matrix
- `data/yelp_homo_adjlists.pickle` — precomputed homogeneous adjacency list (auto-generated by `load_dataset`)
